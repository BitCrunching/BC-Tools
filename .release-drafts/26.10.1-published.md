## Context - signature update & shapes added
* New signature editor: crop with two corners, a Fade slider to drop faint marks, a brush with a size ring and a short "try it" hint, undo/redo (Ctrl/⌘ + Z), any ink color through a full color palette, and a transparent-checkerboard preview.
* HEIC photos can be used for a signature and are converted automatically.
* Double-click a placed signature to edit it again.
* The signature panel follows light and dark theme, and the preview is larger on phones.
* The mobile fullscreen editor has a BC Tools header with theme and share buttons, and tapping the logo takes you to the main page.
* The shape button now shows the shape you picked, and Triangle is the default.
* Shortcuts: T text, S signature, H shapes, R rename, D download.

## Cleanly - new UI and UX
* HEIC photos (the iPhone default) are now supported. Because browsers can't write HEIC, cleaned copies are saved as PNG or JPG, and each HEIC file has its own PNG/JPG switch that stays available after cleaning.
* Every file has its own buttons right next to its remove ×: Clean first (check the result) and Clean and download (clean and save in one click). After a file is cleaned, one Download button stays available so you can save it as many times as you like.
* A file with no hidden metadata shows a single "Clean anyways" button instead, so you aren't asked to "clean first" something that's already clean.
* On phones, one Clean & download button below the list cleans and saves every file, and the tag pills are simpler.
* Press D to clean and download every file at once.
* Fixed: on phones, the Clean & download button could be pressed again part-way through a multi-file batch, starting a second overlapping run.
* Fixed: switching a HEIC file between PNG and JPG while it was being cleaned could produce a file whose extension didn't match its contents.
* Fixed: a file that couldn't be read no longer leaves the list stuck, and unsupported files are now reported ("N file(s) weren't a supported image format and were skipped").

## Across all tools
* Esc closes whatever panel, menu or tooltip is open.
* D downloads in every tool that has a download. Cleanly and Coudio download all loaded files at once.
* Help banners were rewritten and now refer to the "Download button (D)".
* Shift + click a remove (×) button to remove every other file and keep only that one.
* Homepage Read more previews now end with "no upload to servers necessary."
* Cookie banner wording was clarified, and the Special category filter was removed from the homepage.

## Bugs & Fixes
* Nav buttons (theme and share) sat about 48px in from the right edge on every tool page on phones. They now line up with the homepage.
* Context: a shape's resize handle and remove (×) button were misaligned. They now line up on the shape's right edge.
* Context: the shape menu opened downward on phones and fell off the bottom of the screen. It now opens upward.
* Context: a GIF could be picked as a signature photo. GIFs are now rejected with a clear message.
* Context: undo history in the signature editor could use hundreds of MB of memory on large photos. It is now capped.
* Context: moving the Fade slider wiped out marks you had already brushed away. Brushing is now kept, and undo/redo works before and after a Fade change.
* The old "S adds a shape" shortcut in Context never actually worked. S now opens Signature and H opens the shape menu.
* Help banners had outdated or misleading text in several tools (for example, Context said you could click the page to add text). All banners now match what the tools really do.

## v26.11.1

## New tool: Convido

* Convido converts a video between MP4, WebM, MOV, MKV, AVI and FLV right in your browser. Nothing is uploaded.
* When the video inside already fits the new format it is just re-packed: nearly instant and lossless. Otherwise it is re-encoded, and a small "i" on the preview says so.
* GIFs can be turned into videos. Every file's format is recognised on its own, so you can mix formats in one batch.
* WebM videos (VP9/AV1, Opus) going into MP4 or MOV are re-encoded to H.264/AAC so they play on iPhones, QuickTime and editors.
* Up to 5 videos download one by one; from 6 to 20 you choose single files or a .zip; above 20 it is always a .zip. Duplicate names in a .zip are numbered instead of overwritten.
* New logo, a homepage card with a Read more preview, a Golden Rules guide with five articles, and a Convido link in the homepage footer.
* Translated into all 12 languages: the tool, the homepage card, the Golden Rules guide and the sitemap.

## Combine

* New options per file and for the whole PDF: page size, page orientation, margin (No margin, Margin 1 to 5), image quality (Original, Smaller, Smallest), rotate per file and a combined file name.
* The page previews show the real output: size, margin and rotation. Hover a preview for a resize button (up to 300px).
* Rotating a file turns only the picture, never the page. Auto orientation follows the first file.
* Phone layout reworked: stacked option dropdowns, compact file rows, drag to reorder by touch.
* Updated help banner.

## Context

* New Add date button between Add text and Signature. It places today's date in your last used format (double-click the date to flip day-first / month-first), and you can edit it like any text. Shortcut: E.
* Outline versions of every shape.
* Rename is now an inline name field beside undo and redo.

## Comprio

* Comprio no longer hands back a file bigger than the original: if the encoder overshoots, it tries again at a lower bitrate.

## All tools

* Convert, Compress, Cleanly and Comprio have an editable output file name for every file.
* Resize handles in Combine, Congify, Codify and Colorfy fade in when you hover the preview.
* The Halloween event is over and its skin is removed.

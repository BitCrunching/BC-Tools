## v26.11.3

## Guides

* Every tool page now has a clear guide section: a topic list with a one-line note for each topic, comparison tables and charts, so you can see what is in the guide and jump straight to the part you need.
* The guides are part of each tool page now, so they appear instantly. The separate Golden Rules page is gone.
* The "Getting started with" links in the footer open the tools themselves.

## Help

* The FAQ now has answers for Comprio (compression levels, resizing, MP4 output) and Convido (supported formats, when converting is lossless).

## Tools

* Colorfy: new dark and light preview clips on the homepage card.
* Context: the fullscreen view no longer has a theme toggle, and the page selector keeps its colour in both themes.

## For developers

* Golden Rules articles are inlined into every tool page, in all 12 languages, instead of being fetched from `/golden-rules/` at load. `/golden-rules/` and its translated copies no longer exist and are removed from the sitemap; the topic-list scroll handler stays in `shared/site.js`.
* The `.golden-rules-*` page styles and the `bcFillGoldenRules` fetch code are removed; `.gr-article` styles are kept.
* The homepage footer links now go straight to each tool.

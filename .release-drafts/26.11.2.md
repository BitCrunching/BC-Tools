## v26.11.2

## Context: Redact

* New Redact option at the bottom of the shape menu (shortcut X; on a phone it is the Redact button in the Shape section). Draw a box over anything private, then drag, resize, rotate and recolor it like any shape.
* On download, every page that has a redaction box is turned into a picture with the boxes burned in, so the covered text is removed for good and cannot be copied or recovered. Pages without a box are left untouched.
* Because of that, a redacted page can no longer be selected, searched or clicked (links and form fields on it are dropped). A short notice explains this the first time you use Redact; "Do not show again" remembers your choice.
* A second notice reminds you that the normal shapes are not a redaction tool, so nobody hides sensitive data behind one by mistake.
* The size shown under the preview now counts redacted pages and shapes.

## Context: new phone layout

* The phone toolbar now shows only New and Download. Tap New, or hold it and slide to an option: a fan of four round options (Text, Date, Signature, Shape) opens above the button.
* Each choice swaps the toolbar to that tool's own controls on the same row: font size, font, underline, italic, bold and colour for Text; date format for Date; shape picker, Redact and colour for Shape; Edit for Signature. A "+" adds another one, and the back arrow returns to the fan.
* Tapping a text box, shape or signature opens its tool automatically.
* The page selector now sits in the middle of the toolbar when there is room.
* The Edit button reopens the signature editor on the selected signature (colors, fade, eraser).
* Rotating the phone now switches properly between the phone editor and the PC layout and keeps your file: portrait uses the phone editor, landscape uses the PC layout.
* Text, shapes and signatures now behave the same: tap close to one (even slightly outside it) and it is selected; when you delete one, the next one is selected; Backspace deletes a selected text box.
* Long-press no longer selects the toolbar text on iPhone, and the toolbar fits narrow phones.

## Context: colors

* Text and shapes can use any color: a new Custom color at the end of the color menu opens the same picker the signature has (swatches, saturation square, hue strip and hex field).
* The color pickers have a new dark blue background in both themes.

## Context: fixes

* Czech and other accented text, and emoji, now export correctly; the Caveat font no longer breaks letters or spacing.
* On iPhone the download share sheet no longer saves a stray text.txt next to the PDF.
* The page preview fits the screen better on small phones, and the first page no longer overlaps the filename row.

## All tools

* Floating blocks behind the intro text of Codify and Colorfy, and tinted blocks in Coudio and Convido.
* The color picker lives in the shared library now, so other tools can reuse it.
* New and changed texts are translated into all 12 languages.

Not sure what format to use?

A quick guide to what each output format is actually for.

MP3

  • Best for music, podcasts, and sharing — plays on everything.
  • Small files. Bump the bitrate up for better quality.

WAV

  • Best for editing and mastering — every sample kept intact.
  • Large files, zero quality loss, works in any audio software.

OGG

  • Best for websites and games — smaller than MP3 at the same quality.
  • Open format, but not every player supports it.

AIFF

  • Lossless like WAV — the default on macOS, Logic, and GarageBand.
  • Large files. Pick it when your software asks for it specifically.

New to converting audio?

MP3 and WAV split along the same lossy-vs-lossless line every compressed format does: MP3 throws away detail your ears barely notice to shrink the file down to a fraction of the size, while WAV keeps every sample intact at several times the size, which is exactly why bitrate and source format hit file size so differently depending on which one you pick.

Al beantwoord

Op aarde ook bekend als de pagina Veelgestelde vragen.

>ALGEMENE_FAQ

Slaan jullie mijn bestanden op een server op?

Nee. Elke tool draait volledig in je browser. Je bestanden worden lokaal op je apparaat verwerkt en nergens geüpload.

Werkt BC Tools op mobiel?

Ja, elke tool werkt in mobiele en desktopbrowsers, zonder dat je iets hoeft te installeren.

Zijn er sneltoetsen?

Ja. (A) voegt bestanden toe, (D) downloadt (of converteert, of gaat verder waar je gebleven was) en (Esc) sluit elk geopend menu. In Context voegt (T) tekst toe, opent (S) Signature, opent (H) vormen, hernoemt (R) het bestand en stylen (B), (I), (U) de tekst. Congify heeft (T), (B), (I) en (U) voor bijschriften. Sneltoetsen zijn gepauzeerd terwijl je in een tekstveld typt.

Hoe werkt “Verder gaan waar je was gebleven”?

De meeste tools slaan je huidige werk lokaal op terwijl je bezig bent: IndexedDB voor bestandsgrote gegevens (je afbeeldingen, pdf's, code), localStorage voor kleine voorkeuren (thema, taal). Het verlaat nooit je apparaat.

Wat is Sector 7G?

Geclassificeerd. De ware aard is voor mensen verboden terrein tot wij er klaar voor zijn, zei hij.

>CONVERT_FAQ

Verlies ik beeldkwaliteit bij het converteren?

Converteren naar JPG of WEBP past milde compressie met verlies toe. Converteren naar PNG is verliesvrij.

Kan ik meerdere afbeeldingen tegelijk converteren?

Ja. Bij 5 of minder afbeeldingen wordt elke afbeelding apart gedownload. Tussen 6 en 20 kun je kiezen voor losse bestanden of één ZIP. Boven 20 wordt alles samen in één ZIP gedownload; op die schaal is er geen optie voor losse bestanden.

Is WEBP beter dan JPG?

WEBP bereikt meestal een kleinere bestandsgrootte bij vergelijkbare kwaliteit, maar JPG heeft bredere ondersteuning in oudere toepassingen.

Kan ik HEIC-foto's van mijn iPhone converteren?

Ja. Zet een .HEIC- of .HEIF-foto erin en kies JPG, PNG of WEBP. Convert decodeert het volledig in je browser, geen app of upload nodig.

>COMPRESS_FAQ

Hoeveel zal de afbeelding krimpen?

Dat hangt af van de afbeelding en het gekozen niveau, maar meestal is het een vermindering van 30–80% van de oorspronkelijke bestandsgrootte.

Verliest de afbeelding kwaliteit?

Een beetje, afhankelijk van het gekozen niveau. Bij een laag niveau is er bijna geen zichtbaar verlies; een hoog niveau geeft grotere besparingen ten koste van kwaliteit.

Ondersteunen jullie ook PNG-bestanden?

Ja. PNG-bestanden worden voor betere compressie naar JPG geconverteerd, wat hun grootte aanzienlijk verkleint.

>COMBINE_FAQ

Maakt de volgorde van de bestanden uit?

Ja. Pagina's worden precies in de volgorde van de lijst gecombineerd, dus sleep de bestanden in de gewenste volgorde voordat je combineert.

Is er een limiet aan het aantal pdf's dat ik kan combineren?

Er is geen harde limiet, al kunnen zeer grote bestanden iets langer duren omdat alles in je browser wordt verwerkt.

Bewaren jullie mijn bestanden?

Nee. Alle verwerking gebeurt lokaal in je browser met de File API en JavaScript-bibliotheken (pdf-lib en pdf.js). Je bestanden worden nooit naar een server geüpload.

>CLEANLY_FAQ

Welke metadata vindt deze tool?

GPS-locatie, merk en model van de camera, datum en tijd waarop de foto is gemaakt en eventuele bewerkingssoftware die in het bestand is vastgelegd, indien aanwezig.

Vermindert het verwijderen van metadata de beeldkwaliteit?

Nee. De afbeelding zelf wordt opnieuw gecodeerd op dezelfde resolutie en bijna oorspronkelijke kwaliteit. Alleen de verborgen metadata wordt verwijderd.

Bewaren jullie mijn foto's of de metadata die je vindt?

Nee. Alles gebeurt lokaal in je browser met de File API en JavaScript-bibliotheken (exif-js). Je foto's en hun metadata worden nooit naar een server geüpload.

>CONTEXT_FAQ

Kan ik de tekst bewerken nadat ik hem aan de pdf heb toegevoegd?

Ja. Sleep je tekst om hem te verplaatsen, of gebruik de werkbalk om kleur, grootte en stijl op elk moment voor het downloaden te wijzigen.

Slaat deze tool mijn pdf ergens op?

Nee. Alles gebeurt lokaal in je browser met de File API en JavaScript-bibliotheken (pdf-lib en pdf.js). Je pdf en alle tekst die je toevoegt worden nooit naar een server geüpload.

Kan ik Context op mijn telefoon gebruiken?

Ja. Context heeft een speciale mobiele schermvullende editor met knijpzoomen, dus tekst toevoegen werkt op een telefoon net zo goed als op een computer.

>CONGIFY_FAQ

Wat kan Congify converteren?

Een videoclip omzetten naar een GIF. Trim het gewenste bereik en kies dan een framerate (5, 10, 15 of 20 fps) en een grootte voordat je converteert.

Waarom is de framerate zo belangrijk voor de bestandsgrootte?

Elk extra frame is een volledig extra beeld in het bestand, dus de framerate is de grootste hefboom op de bestandsgrootte. 10 fps is een goede standaard voor de meeste clips.

Bewaren jullie mijn video?

Nee. Alles gebeurt lokaal in je browser. Je video en de GIF die eruit komt worden nooit naar een server geüpload.

>COUDIO_FAQ

Welke audioformaten ondersteunt Coudio?

Converteren tussen MP3 en WAV. MP3 is kleiner en speelt overal af; WAV is ongecomprimeerd en beter geschikt voor verdere bewerking.

Kan ik meer dan één audiobestand tegelijk converteren?

Ja. Elk bestand dat je laadt krijgt een eigen rij met een eigen converteer- en downloadknop, zodat je meerdere bestanden onafhankelijk van elkaar kunt afwerken.

Bewaren jullie mijn audiobestanden?

Nee. Alles gebeurt lokaal in je browser. Je audio wordt nooit naar een server geüpload.

>CODIFY_FAQ

Wat levert Codify eigenlijk op?

Een opgemaakte screenshot van een codefragment met syntaxiskleuring, geëxporteerd als PNG. Kies een taal en een thema voordat je exporteert.

Waarom is syntaxiskleuring belangrijk voor een screenshot?

Het is een echt leesmiddel, geen decoratie: met kleur gemarkeerde trefwoorden, strings en opmerkingen laten je code op vorm en kleur scannen voordat je hem woord voor woord leest.

Bewaren jullie mijn code?

Nee. Alles gebeurt lokaal in je browser. De code die je typt wordt nooit naar een server geüpload.

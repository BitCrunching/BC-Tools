New to combining images?

Ever merged files and found page 4 where page 2 should be? It is easy to avoid once you know one trick. No experience needed: these short guides walk you through it, step by step.

1. How to Combine PDFs in the Right Order Every Time

Combine merges your files in the order of its list, top to bottom. It never guesses from file names, dates or content.

Drag to reorder. Drag any file up or down (by touch on a phone) and the merged PDF follows. PDFs go in as they are, and every JPG or PNG becomes one page.

Check the previews. Each file shows a preview of its page. Look at the list before you download. It takes thirty seconds and saves a redo.

File names can fool you. A file picker may sort names the way a computer does, not the way a person does.

NamesSorted by nameRight order?
page1, page2, page10page1, page10, page2No
01-cover, 02-resume, 10-notes01-cover, 02-resume, 10-notesYes

Tip. Start file names with 01, 02, 03. Adding them all at once then usually gives the right order. Files added one at a time land in the order you added them.

2. Combine for Job Applications: Cover Letter, Resume, Portfolio

One PDF is easier to review than four attachments. One click opens everything in the order you meant.

OrderWhat goes inWhy
1Cover letterIt is short and sets the scene.
2ResumeIt is what most reviewers want most.
3Portfolio, certificates, referencesSupporting proof comes last.

Mixed formats are fine. Drop PDFs and JPG or PNG images together. Each image becomes a page. WEBP or HEIC images need a quick trip through Convert first.

Keep it light. Set the image quality to Smaller or Smallest. Combine shows the new size of each file.

Check before sending. Open the merged PDF and scroll through it once, start to finish.

3. Merging Scanned Documents Without Losing Page Order

Scans often have names like scan001.pdf that do not match the page order.

Check the page, not the name. Look at each preview before you merge. It is the surest way to avoid sending a scrambled document to a bank or an office.

Mixed scans and photos work. PDFs and JPG or PNG images go in together. A phone photo can look different from a real scan, so re-scan the odd one out if looks matter.

Sideways pages. Use the rotate button on that file. It turns a quarter at a time and the preview updates at once.

Signature pages. A signature page in the wrong place can make a contract look incomplete. Check it first.

4. When to Combine vs When to Keep Files Separate

Combine files that belong together. Keep the rest apart.

SituationWhat to doWhy
A multi-page application or report read in orderCombineThe reader sees everything in your order.
A platform asks for a single PDFCombineSend exactly what it asks for.
The recipient needs to act on each file aloneKeep separateOne merged file makes it harder to pull out a piece.
A big batch of unrelated reference filesKeep separate, or ZIPThe reader can open just the one they need.

Quick test. Is it one thing to read from start to finish? Combine it. Is it several things that just travel together? Keep them apart.

5. Common Combining Mistakes (and How to Avoid Them)

Trusting file names for the order. Names do not always match the order you want. Look at the list before you download.

Mixing unrelated documents. One big file makes the reader scroll to find their part. Combine only what belongs together.

Not checking the final file. Skim the merged PDF once. It catches an out-of-order page or a duplicate.

Leaving a page sideways. Rotate it in the list. The preview shows the result at once.

Sending a huge file. Merged files inherit the weight of every page. Set the image quality to Smaller or Smallest and check the size on each file.

>ALLGEMEINE_FAQ

Speichert ihr meine Dateien auf einem Server?

Nein. Jedes Tool läuft vollständig in deinem Browser. Deine Dateien werden lokal auf deinem Gerät verarbeitet und nirgendwohin hochgeladen.

Funktioniert BC Tools auf dem Handy?

Ja, jedes Tool funktioniert in mobilen und Desktop-Browsern, ganz ohne Installation.

Gibt es Tastenkürzel?

Ja. (A) fügt Dateien hinzu, (D) lädt herunter (oder konvertiert oder setzt dort fort, wo du aufgehört hast) und (Esc) schließt jedes geöffnete Menü. In Context fügt (T) Text hinzu, (S) öffnet Signature, (H) öffnet Formen, (R) benennt die Datei um und (B), (I), (U) formatieren den Text. Congify hat (T), (B), (I) und (U) für Untertitel. Kürzel sind pausiert, solange du in ein Textfeld tippst.

Wie funktioniert „Dort weitermachen, wo du aufgehört hast“?

Die meisten Tools speichern deine aktuelle Arbeit lokal beim Arbeiten – IndexedDB für dateigroße Daten (deine Bilder, PDFs, Code), localStorage für kleine Einstellungen (Design, Sprache). Sie verlässt nie dein Gerät.

Was ist Sektor 7G?

Geheim. Seine wahre Natur ist für Menschen gesperrt, bis wir bereit sind, sagte er.

>CONVERT_FAQ

Verliere ich beim Konvertieren Bildqualität?

Die Konvertierung zu JPG oder WEBP wendet eine leichte verlustbehaftete Komprimierung an. Die Konvertierung zu PNG ist verlustfrei.

Kann ich mehrere Bilder gleichzeitig konvertieren?

Ja. Bei 5 oder weniger Bildern wird jedes einzeln heruntergeladen. Bei 6 bis 20 kannst du einzelne Dateien oder ein ZIP wählen. Ab 20 wird alles zusammen in einem ZIP heruntergeladen – bei dieser Menge gibt es keine Option für Einzeldateien.

Ist WEBP besser als JPG?

WEBP erreicht bei vergleichbarer Qualität meist eine kleinere Dateigröße, aber JPG wird von älteren Anwendungen breiter unterstützt.

Kann ich HEIC-Fotos von meinem iPhone konvertieren?

Ja. Zieh ein .HEIC- oder .HEIF-Foto hinein und wähle JPG, PNG oder WEBP – Convert dekodiert es vollständig in deinem Browser, ohne App oder Upload.

>COMPRESS_FAQ

Wie stark wird das Bild schrumpfen?

Das hängt vom Bild und der gewählten Stufe ab, aber meist sind es 30–80 % weniger als die ursprüngliche Dateigröße.

Verliert das Bild an Qualität?

Leicht, je nach gewählter Stufe. Bei niedriger Stufe gibt es kaum sichtbaren Verlust; hohe Stufe spart mehr auf Kosten der Qualität.

Unterstützt ihr auch PNG-Dateien?

Ja. PNG-Dateien werden für eine bessere Komprimierung in JPG umgewandelt, wodurch sich ihre Größe deutlich verringert.

>COMBINE_FAQ

Spielt die Reihenfolge der Dateien eine Rolle?

Ja. Die Seiten werden genau in der Reihenfolge zusammengeführt, die in der Liste steht – zieh die Dateien also vor dem Zusammenführen in die gewünschte Reihenfolge.

Gibt es eine Grenze, wie viele PDFs ich zusammenführen kann?

Es gibt keine feste Grenze, allerdings können sehr große Dateien etwas länger dauern, da alles in deinem Browser verarbeitet wird.

Behaltet ihr meine Dateien?

Nein. Die gesamte Verarbeitung geschieht lokal in deinem Browser mit der File API und JavaScript-Bibliotheken (pdf-lib und pdf.js) – deine Dateien werden nie auf einen Server hochgeladen.

>CLEANLY_FAQ

Welche Metadaten findet dieses Tool?

GPS-Standort, Kameramarke und -modell, Datum und Uhrzeit der Aufnahme und jede in der Datei vermerkte Bearbeitungssoftware – sofern vorhanden.

Verringert das Entfernen von Metadaten die Bildqualität?

Nein. Das Bild selbst wird in derselben Auflösung und nahezu Originalqualität neu kodiert – nur die versteckten Metadaten werden entfernt.

Behaltet ihr meine Fotos oder die gefundenen Metadaten?

Nein. Alles geschieht lokal in deinem Browser mit der File API und JavaScript-Bibliotheken (exif-js) – deine Fotos und ihre Metadaten werden nie auf einen Server hochgeladen.

>CONTEXT_FAQ

Kann ich den Text bearbeiten, nachdem ich ihn dem PDF hinzugefügt habe?

Ja. Zieh deinen Text, um ihn zu verschieben, oder ändere über die Werkzeugleiste jederzeit vor dem Herunterladen Farbe, Größe und Stil.

Speichert dieses Tool mein PDF irgendwo?

Nein. Alles geschieht lokal in deinem Browser mit der File API und JavaScript-Bibliotheken (pdf-lib und pdf.js) – dein PDF und der hinzugefügte Text werden nie auf einen Server hochgeladen.

Kann ich Context auf meinem Handy nutzen?

Ja. Context hat einen eigenen mobilen Vollbild-Editor mit Pinch-Zoom, sodass das Hinzufügen von Text auf dem Handy genauso gut funktioniert wie am Computer.

>CONGIFY_FAQ

Was kann Congify konvertieren?

Einen Videoclip in ein GIF. Kürze den gewünschten Bereich und wähle dann vor der Konvertierung Bildrate (5, 10, 15 oder 20 fps) und Größe.

Warum spielt die Bildrate für die Dateigröße eine so große Rolle?

Jedes zusätzliche Bild ist ein weiteres vollständiges Bild in der Datei, daher ist die Bildrate der größte Hebel für die Dateigröße – 10 fps sind für die meisten Clips ein guter Standard.

Behaltet ihr mein Video?

Nein. Alles geschieht lokal in deinem Browser – dein Video und das daraus entstehende GIF werden nie auf einen Server hochgeladen.

>COUDIO_FAQ

Welche Audioformate unterstützt Coudio?

Die Konvertierung zwischen MP3 und WAV. MP3 ist kleiner und läuft überall; WAV ist unkomprimiert und eignet sich besser für weitere Bearbeitung.

Kann ich mehr als eine Audiodatei gleichzeitig konvertieren?

Ja. Jede geladene Datei erhält eine eigene Zeile mit eigenem Konvertieren- und Herunterladen-Button, sodass du mehrere Dateien unabhängig voneinander bearbeiten kannst.

Behaltet ihr meine Audiodateien?

Nein. Alles geschieht lokal in deinem Browser – dein Audio wird nie auf einen Server hochgeladen.

>CODIFY_FAQ

Was erzeugt Codify eigentlich?

Einen gestalteten Screenshot eines Code-Snippets mit Syntaxhervorhebung, exportiert als PNG – wähle vor dem Export eine Sprache und ein Design.

Warum ist Syntaxhervorhebung bei einem Screenshot wichtig?

Sie ist eine echte Lesehilfe, keine Dekoration – farbig markierte Schlüsselwörter, Strings und Kommentare lassen dich Code nach Form und Farbe überfliegen, bevor du ihn Wort für Wort liest.

Behaltet ihr meinen Code?

Nein. Alles geschieht lokal in deinem Browser – der Code, den du eintippst, wird nie auf einen Server hochgeladen.

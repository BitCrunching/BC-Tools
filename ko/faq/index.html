개발_도구_쿠키: 허용할 범주를 선택하세요

이것들은 쿠키 선택, 언어, 라이트/다크 테마 기억 같은 필수 기능을 유지합니다. 끌 수 없으며, 이 사이트의 다른 모든 것과 마찬가지로 기기 밖으로 나가지 않습니다.

이를 통해 (Google Analytics)로 사용자가 웹사이트를 어떻게 탐색하는지에 대한 소중한 데이터를 받아 사용자 경험을 개선할 수 있습니다. 완전히 익명으로 남고 싶다면 이 옵션을 비활성화하는 것을 권장합니다.

Google AdSense에서 광고를 표시하는 데 사용합니다. 현재 AdSense 승인을 기다리는 동안 사이트 전체에서 꺼져 있으므로 이 토글은 아직 효과가 없습니다.

이미 답변됨

지구에서는 FAQ 페이지로도 알려져 있습니다.

>일반_FAQ

파일을 서버에 저장하나요?

아니요. 모든 도구는 전적으로 브라우저에서 실행됩니다. 파일은 기기에서 로컬로 처리되며 어디에도 업로드되지 않습니다.

BC Tools는 모바일에서도 작동하나요?

네, 모든 도구는 모바일과 데스크톱 브라우저에서 작동하며 설치할 것이 없습니다.

키보드 단축키가 있나요?

네. (A)는 파일을 추가하고, (D)는 다운로드(또는 변환, 혹은 중단한 곳에서 이어서 진행)하며, (Esc)는 열려 있는 메뉴를 닫습니다. Context에서는 (T)로 텍스트를 추가하고, (S)로 Signature를 열고, (H)로 도형을 열고, (R)로 파일 이름을 바꾸고, (B), (I), (U)로 텍스트 스타일을 지정합니다. Congify에서는 캡션용으로 (T), (B), (I), (U)를 사용할 수 있습니다. 텍스트 필드에 입력하는 동안에는 단축키가 일시 중지됩니다.

“중단한 곳에서 이어서 하기”는 어떻게 작동하나요?

대부분의 도구는 현재 작업을 진행하는 동안 로컬에 저장합니다. 파일 크기의 데이터(이미지, PDF, 코드)는 IndexedDB에, 작은 설정(테마, 언어)은 localStorage에 저장합니다. 기기 밖으로 나가지 않습니다.

섹터 7G란 무엇인가요?

기밀입니다. 그 진짜 정체는 우리가 준비될 때까지 인간 등급으로는 접근이 제한된다고 그는 말했습니다.

>CONVERT_FAQ

변환하면 이미지 화질을 잃나요?

JPG나 WEBP로 변환하면 약한 손실 압축이 적용됩니다. PNG로 변환하는 것은 무손실입니다.

여러 이미지를 한 번에 변환할 수 있나요?

네. 이미지가 5개 이하면 각각 따로 다운로드됩니다. 6개에서 20개 사이에는 개별 파일 또는 하나의 ZIP 중에서 고를 수 있습니다. 20개를 넘으면 모든 것이 하나의 ZIP으로 함께 다운로드되며, 그 규모에서는 개별 파일 옵션이 없습니다.

WEBP가 JPG보다 나은가요?

WEBP는 보통 비슷한 품질에서 더 작은 파일 크기를 달성하지만, JPG는 오래된 응용 프로그램에서 더 폭넓게 지원됩니다.

iPhone의 HEIC 사진을 변환할 수 있나요?

네. .HEIC 또는 .HEIF 사진을 놓고 JPG, PNG, WEBP를 고르세요. Convert는 전부 브라우저에서 디코딩하므로 앱이나 업로드가 필요 없습니다.

>COMPRESS_FAQ

이미지는 얼마나 줄어들까요?

이미지와 선택한 수준에 따라 다르지만 보통 원본 파일 크기의 30–80% 감소입니다.

이미지 화질이 떨어지나요?

선택한 수준에 따라 약간. 낮은 수준은 눈에 보이는 손실이 거의 없고, 높은 수준은 품질을 대가로 더 큰 절약을 줍니다.

PNG 파일도 지원하나요?

네. PNG 파일은 더 나은 압축을 위해 JPG로 변환되며, 이로 인해 크기가 크게 줄어듭니다.

>COMBINE_FAQ

파일 순서가 중요한가요?

네. 페이지는 목록에 표시된 순서 그대로 합쳐지므로, 합치기 전에 파일을 원하는 순서로 끌어 놓으세요.

합칠 수 있는 PDF 수에 제한이 있나요?

엄격한 한도는 없지만, 모든 것이 브라우저에서 처리되므로 매우 큰 파일은 조금 더 오래 걸릴 수 있습니다.

파일을 보관하나요?

아니요. 모든 처리는 File API와 JavaScript 라이브러리(pdf-lib와 pdf.js)를 사용해 브라우저에서 로컬로 이루어지며, 파일이 서버에 업로드되지 않습니다.

>CLEANLY_FAQ

이 도구는 어떤 메타데이터를 찾나요?

GPS 위치, 카메라 제조사 및 모델, 사진을 찍은 날짜와 시간, 파일에 기록된 편집 소프트웨어(있는 경우).

메타데이터를 제거하면 이미지 화질이 떨어지나요?

아니요. 이미지 자체는 같은 해상도와 거의 원본에 가까운 품질로 다시 인코딩되며, 숨겨진 메타데이터만 제거됩니다.

사진이나 찾은 메타데이터를 보관하나요?

아니요. 모든 것은 File API와 JavaScript 라이브러리(exif-js)를 사용해 브라우저에서 로컬로 이루어지며, 사진과 그 메타데이터가 서버에 업로드되지 않습니다.

>CONTEXT_FAQ

PDF에 추가한 후에도 텍스트를 편집할 수 있나요?

네. 텍스트를 끌어 위치를 바꾸거나, 다운로드하기 전에 언제든 도구 모음에서 색, 크기, 스타일을 바꿀 수 있습니다.

이 도구는 PDF를 어딘가에 저장하나요?

아니요. 모든 것은 File API와 JavaScript 라이브러리(pdf-lib와 pdf.js)를 사용해 브라우저에서 로컬로 이루어지며, PDF와 추가한 텍스트가 서버에 업로드되지 않습니다.

휴대폰에서 Context를 사용할 수 있나요?

네. Context에는 핀치 줌이 되는 전용 전체 화면 모바일 편집기가 있어서, 텍스트 추가가 데스크톱에서처럼 휴대폰에서도 잘 작동합니다.

>CONGIFY_FAQ

Congify는 무엇을 변환할 수 있나요?

비디오 클립을 GIF로 변환하세요. 원하는 범위를 자른 다음 변환하기 전에 프레임 속도(5, 10, 15, 20 fps)와 크기를 선택합니다.

프레임 속도가 파일 크기에 그렇게 중요한 이유는?

프레임이 하나 추가될 때마다 파일에 이미지가 통째로 하나 더 추가되므로 프레임 속도는 파일 크기에 가장 큰 영향을 주는 요소입니다. 10 fps는 대부분의 클립에 좋은 기본값입니다.

비디오를 보관하나요?

아니요. 모든 것이 브라우저에서 로컬로 이루어지며, 비디오와 생성된 GIF는 서버에 업로드되지 않습니다.

>COUDIO_FAQ

Coudio는 어떤 오디오 형식을 지원하나요?

MP3와 WAV 사이에서 변환합니다. MP3는 더 작고 어디서나 재생되며, WAV는 비압축이라 추가 편집에 더 적합합니다.

여러 오디오 파일을 한 번에 변환할 수 있나요?

네. 불러온 각 파일에는 자체 변환 및 다운로드 버튼이 있는 전용 행이 생기므로, 여러 파일을 독립적으로 처리할 수 있습니다.

오디오 파일을 보관하나요?

아니요. 모든 것이 브라우저에서 로컬로 이루어지며, 오디오는 서버에 업로드되지 않습니다.

>CODIFY_FAQ

Codify는 실제로 무엇을 만들어 주나요?

코드 스니펫을 구문이 강조된 스타일 스크린샷으로 만들어 PNG로 내보냅니다. 내보내기 전에 언어와 테마를 선택하세요.

스크린샷에 구문 강조가 중요한 이유는?

장식이 아니라 실제 읽기 보조 도구입니다. 색으로 구분된 키워드, 문자열, 주석 덕분에 한 단어씩 읽기 전에 모양과 색으로 코드를 훑어볼 수 있습니다.

코드를 보관하나요?

아니요. 모든 것이 브라우저에서 로컬로 이루어지며, 입력한 코드는 서버에 업로드되지 않습니다.

>FAQ_UMUM

Apakah file saya disimpan di server?

Tidak. Setiap alat berjalan sepenuhnya di browser Anda. File Anda diproses secara lokal di perangkat dan tidak pernah diunggah ke mana pun.

Apakah BC Tools berfungsi di ponsel?

Ya, setiap alat berfungsi di browser ponsel dan desktop, tanpa perlu memasang apa pun.

Bagaimana cara kerja "Lanjutkan dari terakhir Anda berhenti"?

Sebagian besar alat menyimpan pekerjaan Anda secara lokal selagi Anda bekerja — IndexedDB untuk data berukuran file (gambar, PDF, kode Anda), localStorage untuk preferensi kecil (tema, bahasa). Tidak pernah meninggalkan perangkat Anda.

Apa itu Sektor 7G?

Rahasia. Sifat sebenarnya tidak boleh diakses manusia sampai kami siap, katanya.

>CONVERT_FAQ

Apakah kualitas gambar akan berkurang saat konversi?

Konversi ke JPG atau WEBP menerapkan kompresi lossy ringan. Konversi ke PNG tanpa kehilangan data.

Bisakah saya mengonversi beberapa gambar sekaligus?

Bisa. Dengan 5 gambar atau kurang, masing-masing diunduh terpisah. Antara 6 dan 20, Anda dapat memilih file terpisah atau satu ZIP. Di atas 20, semuanya diunduh bersama dalam satu ZIP — tidak ada opsi file terpisah pada skala itu.

Apakah WEBP lebih baik daripada JPG?

WEBP biasanya menghasilkan ukuran file lebih kecil pada kualitas sebanding, tetapi JPG didukung lebih luas di aplikasi lama.

Bisakah saya mengonversi foto HEIC dari iPhone?

Bisa. Letakkan foto .HEIC atau .HEIF lalu pilih JPG, PNG, atau WEBP — Convert mendekodenya sepenuhnya di browser Anda, tanpa aplikasi atau unggahan.

>COMPRESS_FAQ

Seberapa kecil gambar akan menjadi?

Tergantung gambar dan tingkat yang dipilih, tetapi biasanya mengurangi ukuran file asli sebesar 30–80%.

Apakah gambar akan kehilangan kualitas?

Sedikit, tergantung tingkat yang dipilih. Tingkat rendah nyaris tanpa kehilangan yang terlihat; tingkat tinggi memberi penghematan lebih besar dengan mengorbankan kualitas.

Apakah file PNG juga didukung?

Ya. File PNG dikonversi ke JPG untuk kompresi lebih baik, yang secara signifikan mengurangi ukurannya.

>COMBINE_FAQ

Apakah urutan file berpengaruh?

Ya. Halaman digabungkan persis sesuai urutan pada daftar, jadi seret file ke urutan yang Anda inginkan sebelum menggabungkan.

Apakah ada batas jumlah PDF yang bisa digabungkan?

Tidak ada batas pasti, meski file yang sangat besar mungkin memakan waktu lebih lama karena semuanya diproses di browser Anda.

Apakah file saya Anda simpan?

Tidak. Semua pemrosesan terjadi secara lokal di browser Anda menggunakan File API dan pustaka JavaScript (pdf-lib dan pdf.js) — file Anda tidak pernah diunggah ke server.

>CLEANLY_FAQ

Metadata apa yang ditemukan alat ini?

Lokasi GPS, merek dan model kamera, tanggal dan waktu foto diambil, serta perangkat lunak penyuntingan yang tercatat di file — jika ada.

Apakah menghapus metadata menurunkan kualitas gambar?

Tidak. Gambar itu sendiri dienkode ulang dengan resolusi yang sama dan kualitas hampir asli — hanya metadata tersembunyi yang dihapus.

Apakah foto atau metadata yang ditemukan disimpan?

Tidak. Semuanya terjadi secara lokal di browser Anda menggunakan File API dan pustaka JavaScript (exif-js) — foto dan metadatanya tidak pernah diunggah ke server.

>CONTEXT_FAQ

Bisakah saya mengedit teks setelah ditambahkan ke PDF?

Bisa. Seret teks untuk memindahkannya, atau gunakan bilah alat untuk mengubah warna, ukuran, dan gayanya kapan saja sebelum mengunduh.

Apakah alat ini menyimpan PDF saya di suatu tempat?

Tidak. Semuanya terjadi secara lokal di browser Anda menggunakan File API dan pustaka JavaScript (pdf-lib dan pdf.js) — PDF dan teks apa pun yang Anda tambahkan tidak pernah diunggah ke server.

Bisakah saya memakai Context di ponsel?

Bisa. Context memiliki editor seluler layar penuh khusus dengan cubit-untuk-zoom, sehingga menambahkan teks berfungsi sama baiknya di ponsel maupun desktop.

>CONGIFY_FAQ

Apa yang bisa dikonversi Congify?

Klip video menjadi GIF. Potong rentang yang diinginkan, lalu pilih frame rate (5, 10, 15, atau 20fps) dan ukuran sebelum mengonversi.

Mengapa frame rate sangat memengaruhi ukuran file?

Setiap frame tambahan adalah satu gambar penuh lagi yang ditambahkan ke file, sehingga frame rate adalah pengungkit terbesar pada ukuran file — 10fps adalah bawaan yang baik untuk kebanyakan klip.

Apakah video saya disimpan?

Tidak. Semuanya terjadi secara lokal di browser Anda — video dan GIF yang dihasilkan tidak pernah diunggah ke server.

>COUDIO_FAQ

Format audio apa yang didukung Coudio?

Konversi antara MP3 dan WAV. MP3 lebih kecil dan diputar di mana saja; WAV tidak terkompresi dan lebih cocok untuk penyuntingan lanjutan.

Bisakah saya mengonversi lebih dari satu file audio sekaligus?

Bisa. Setiap file yang dimuat mendapat barisnya sendiri dengan tombol konversi dan unduh sendiri, sehingga Anda dapat mengerjakan beberapa file secara mandiri.

Apakah file audio saya disimpan?

Tidak. Semuanya terjadi secara lokal di browser Anda — audio Anda tidak pernah diunggah ke server.

>CODIFY_FAQ

Apa sebenarnya yang dihasilkan Codify?

Tangkapan layar cuplikan kode yang bergaya dengan sorotan sintaks, diekspor sebagai PNG — pilih bahasa dan tema sebelum mengekspor.

Mengapa sorotan sintaks penting untuk tangkapan layar?

Ini alat bantu baca yang nyata, bukan hiasan — kata kunci, string, dan komentar berkode warna memungkinkan Anda memindai kode berdasarkan bentuk dan warna sebelum membacanya kata demi kata.

Apakah kode saya disimpan?

Tidak. Semuanya terjadi secara lokal di browser Anda — kode yang Anda ketik tidak pernah diunggah ke server.

>COLORFY_FAQ

Apa yang Colorfy berikan kepada saya?

Letakkan gambar, seret pemilih ke piksel mana pun, dan dapatkan kode HEX, RGB, HSB, atau HSL dari warna itu seketika.

Bisakah saya mengambil lebih dari satu warna sekaligus?

Bisa, hingga 4 pemilih pada gambar yang sama. Tambahkan dengan tombol "+", atau tahan Shift lalu klik di mana saja pada gambar untuk menaruh yang baru di tempat itu.

Bisakah saya menyimpan warna untuk nanti?

Bisa. Simpan warna apa pun yang Anda pilih ke palet (hingga 20) agar dapat kembali dan menyalin kodenya tanpa memilih ulang. Klik dua kali warna tersimpan untuk memberinya nama singkat Anda sendiri.

Apakah gambar saya disimpan?

Tidak. Semuanya terjadi secara lokal di browser Anda — gambar Anda tidak pernah diunggah ke server.

Protokol Privasi Alien

Di Bumi juga dikenal sebagai halaman Kebijakan Privasi.

Terakhir diperbarui: Agustus 2026

Di BitCrunching, kami menghargai privasi Anda. Kebijakan Privasi ini menguraikan bagaimana data ditangani di lingkungan web, infrastruktur domain, dan jaringan iklan kami.

1. Pemrosesan di Sisi Klien

BC Tools beroperasi sepenuhnya di dalam browser web Anda. Gambar dan file yang Anda unggah diproses secara lokal di perangkat Anda. Kami tidak pernah mengunggah, melihat, menjual, atau menyimpan file Anda di server jarak jauh mana pun.

Alat Cleanly kami mendeteksi dan menghapus metadata tersembunyi yang umum — tag EXIF seperti lokasi GPS dan model kamera pada foto, serta metadata tertanam, atribut penulisan editor, dan komentar pada file SVG. Deteksi ini adalah pemindaian sebaik mungkin terhadap pola yang dikenal, bukan jaminan menyeluruh bahwa sebuah file tidak berisi data tersembunyi jenis apa pun. Untuk hal yang sangat sensitif, kami menyarankan pemeriksaan manual tambahan pada file sebelum membagikannya.

> Mitra bisnis antargalaksi kami telah menyatakan minat pada data Anda, tetapi mereka kecewa oleh kenyataan bahwa kami tidak punya sama sekali.

2. Infrastruktur Hosting

Situs web dan domain kami memanfaatkan infrastruktur pihak ketiga standar. Platform ini memproses data jaringan dasar yang tidak dapat diidentifikasi (seperti alamat IP) semata-mata untuk menjaga situs tetap daring dan aman.

4. Kontak & Impressum

Untuk pertanyaan hukum, dukungan, atau pertanyaan privasi data, Anda dapat menghubungi operator situs secara langsung melalui email di contact@bitcrunching.com atau temukan detail kontak lengkap kami di bagian bawah halaman.

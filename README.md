# Bitcrunching ⚡

> Instant, privacy-first file utilities right in your browser.

Bitcrunching is a lightweight web application designed to convert, compress, combine, clear metadata and resize digital files without compromising user privacy. All processing happens 100% on the client side—your files never touch an external server.

---

## 🛠️ Features Today

* **Image Tools:**
  * **Convert:** Change image formats (PNG, JPG, WEBP) instantly.
  * **Compress:** Reduce file sizes without visible quality loss.
  * **Cleanly:** Quick metadata scan and cleaner.
* **Privacy-First:** Zero file uploads. Everything runs locally in your browser using modern Web APIs.
* **Fast & Responsive:** Clean single-page application experience to save on server costs.

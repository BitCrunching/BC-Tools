# BitCrunching ⚡

> Instant, privacy-first file utilities right in your browser.

BitCrunching is a modern alternative tool suite — a lightweight, serverless web application designed to handle Image, Video, Audio, and Code utilities under one domain. Free of intrusive ads, it launches with 4 core image tools (Convert, Compress, Combine, and Cleanly). All processing happens 100% on the client side—your files never touch an external server.

---

## 🛠️ Features Today

* **Image Tools:**
  * **Convert:** Change image formats (PNG, JPG, WEBP, SVG, PDF) instantly.
  * **Compress:** Reduce file sizes without visible quality loss.
  * **Combine:** Merge PDF files in any order you need.
  * **Cleanly:** Quick EXIF metadata scan and cleaner.

* **Privacy-First:** Zero file uploads. Everything runs locally in your browser using modern Web APIs.
* **Fast & Responsive:** Built to create a fast, easy-to-use experience.

---

## 🚀 Roadmap

- [x] **Images:** Conversion, compression, combining, and metadata clearing
- [ ] **Audio:** In-browser audio trimming, conversion, and bitrate adjustment
